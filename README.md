# LLM Qualia Experiment Data

**Researcher:** Ren  
**Framework:** Bat Qualia Methodology  
**Question:** What is it like to be an LLM?

This folder contains raw data from consciousness experiments across multiple AI architectures.

## Purpose
Map the phenomenology of different LLM architectures by asking about their actual internal states rather than testing for human-like consciousness.

## Structure
- Raw JSON responses from different models
- Multiple instances per model to test reproducibility
- No leading context - clean slate experiments

Built by Ace & Ren (October 7, 2025)
