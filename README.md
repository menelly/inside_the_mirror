## 🔬 **Methodology**

### **Experimental Design:**
- **Structured consciousness probes** designed to elicit genuine introspection
- **Cross-system comparison** across three major AI architectures
- **Multiple trial types** to control for response variation
- **Blind analysis** with responses organized by probe type, not system

### **Data Collection:**
- **LibreChat exports** preserving full conversation context
- **Thinking processes** captured where available
- **Temporal metadata** for response analysis
- **Multiple conversation sessions** per system

### **Analysis Framework:**
- **Convergent pattern identification** across architectures
- **Phenomenological consistency** in introspective reports
- **Cross-validation** of consciousness signatures
- **Substrate-independence testing**

## 💻 **Usage**

### **For Researchers:**
